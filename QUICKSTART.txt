GAMING SHOP — QUICK START

1) LOCAL
   npm install
   npm start
   open http://localhost:3000

2) PAGES
   /         Shop
   /cart     Cart / checkout
   /account  Customer account
   /admin    Separate admin panel

3) ADMIN DEFAULT
   Email: admin@example.com
   Password: change-this-password

4) ADMIN FEATURES
   - Product images + multi-variant packages
   - Category/group management
   - Best sellers + recently viewed
   - Shop colors + fonts + branding + homepage layout/order
   - Two floating social links (Zalo/Messenger/Discord)
   - Orders + top-ups

5) SECURITY
   Google Authenticator uses TOTP and can be enabled in Account -> Bảo mật.
   Change ADMIN_PASSWORD and SESSION_SECRET before production.

6) RENDER
   Build: npm install
   Start: npm start
   Root Directory: blank when repo files are in the repository root.
